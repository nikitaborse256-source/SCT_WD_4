# SkillCraft Technology – Web Development Internship (Task 4)

## 🖥 Project Overview
This project is part of *Task 4* for the *Web Development Internship* at *SkillCraft Technology*.  
The goal of this task is to create a *Tribute Page* dedicated to a great personality using basic web technologies like *HTML* and *CSS*.  
The page highlights the achievements and contributions of the person in a visually appealing and well-structured layout.

- Beautifully designed tribute layout using HTML and CSS  
- Structured content with headings, paragraphs, and images  
- Responsive and clean interface  
- Well-aligned sections with smooth readability  
- Simple and easy-to-understand code
